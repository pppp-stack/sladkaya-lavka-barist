# Сладкая лавка — стиль Barist

Лендинг в композиции [barist.ru](https://barist.ru/), переделанный под тематику «Сладкая лавка».
Используются изображения из основного магазина.

## Запуск

```bash
npm install
npm run dev
```

Откроется на **http://localhost:3002/**

## Скрипты

- `npm run dev` — разработка (порт 3002)
- `npm run build` — production-сборка
- `npm run preview` — превью сборки на 3002
